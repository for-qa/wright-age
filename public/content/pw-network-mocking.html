🎯 What is it?

Network Interception & Mocking

Think of a flight simulator: pilots practice engine failure without crashing a real plane. page.route() lets your tests practice declined cards, 500 errors, and timeouts without waiting for production to break.

Playwright sits between your app and the network — you decide whether each request gets real data, fake data, or no response at all.

💻 Code Example

page.route() Fundamentals

Register a handler before navigation — like putting a filter on the water pipe before opening the tap.

test('intercept products API', async ({ page }) => {
  await page.route('**/api/products', async (route) => {
    await route.fulfill({
      status: 200,
      contentType: 'application/json',
      body: JSON.stringify([
        { id: '1', name: 'Mocked Product', price: 99.99 },
        { id: '2', name: 'Another Mock', price: 49.99 },
      ]),
    });
  });

  await page.goto('/products');

  await expect(page.getByText('Mocked Product')).toBeVisible();
  await expect(page.getByText('$99.99')).toBeVisible();
});

Each handler can fulfill (mock), continue (forward), or abort (fail).

📋 Reference

Route Matching Patterns

// Exact URL
await page.route('https://api.shop.com/products', handler);

// Glob — any domain
await page.route('**/api/products', handler);
await page.route('**/api/products/*', handler);

// Regex — product by ID
await page.route(/\/api\/products\/\d+/, handler);

// Function predicate
await page.route(
  (url) => url.pathname.startsWith('/api/') && url.searchParams.has('mock'),
  handler
);
⚙️ How It Works

Three Response Patterns

1
Fulfill — return mock data
await page.route('**/api/cart', async (route) => {
  await route.fulfill({
    status: 200,
    contentType: 'application/json',
    body: JSON.stringify({ items: [...], total: 65.38 }),
  });
});
2
Continue — modify real response
await page.route('**/api/products/*', async (route) => {
  const response = await route.fetch();
  const json = await response.json();
  json.price = json.price * 0.9;  // 10% sale
  await route.fulfill({ response, body: JSON.stringify(json) });
});
3
Abort — simulate failure
await page.route('**/api/recommendations', async (route) => {
  await route.abort('failed');
});
// Also: 'timedout', 'connectionrefused', 'internetdisconnected', ...

🛒 Real-Life Example

Mocking Shipping Calculations

Read the request body and return different options — like a dispatcher who changes routes based on ZIP code.

await page.route('**/api/shipping/calculate', async (route) => {
  const postData = JSON.parse(route.request().postData() || '{}');
  const options = postData.zipCode?.startsWith('96')
    ? [{ id: 'express', name: 'Express (5-7 days)', price: 45.99 }]
    : [
        { id: 'standard', name: 'Standard (5-7 days)', price: 5.99 },
        { id: 'express', name: 'Express (2-3 days)', price: 15.99 },
      ];
  await route.fulfill({ status: 200, body: JSON.stringify({ options }) });
});

Simulating Network Conditions

A
Slow network
await page.route('**/api/**', async (route) => {
  await new Promise(r => setTimeout(r, 3000));
  await route.continue();
});
await expect(page.getByTestId('loading-spinner')).toBeVisible();
B
Offline mode
await context.setOffline(true);
await page.getByRole('button', { name: 'Add to Cart' }).click();
await expect(page.getByText(/offline|no connection/i)).toBeVisible();
await context.setOffline(false);
C
Intermittent failures (retry)
let requestCount = 0;
await page.route('**/api/cart/add', async (route) => {
  requestCount++;
  if (requestCount < 3) {
    await route.fulfill({ status: 500, body: 'Internal Server Error' });
  } else {
    await route.fulfill({ status: 200, body: JSON.stringify({ cartCount: 1 }) });
  }
});
await expect(page.getByTestId('cart-count')).toHaveText('1');
expect(requestCount).toBe(3);

HAR Recording & Playback

HAR files are like DVR recordings of network traffic — capture once during development, replay forever in CI without hitting real APIs.

// Record mode
await page.routeFromHAR('./hars/checkout.har', {
  update: true,
  updateContent: 'embed',
});

// Playback mode — no real network
await page.routeFromHAR('./hars/checkout.har', {
  update: false,
  notFound: 'abort',
});

// Config: record minimal HAR in CI for debugging
har: process.env.CI ? { path: './test-results/network.har', mode: 'minimal' } : undefined

Mock Fixtures

Reusable fixtures wrap common mocks — one line to simulate declined payment across many tests.

export const test = base.extend<MockFixtures>({
  mockPayment: async ({ page }, use) => {
    const mock = async (result: 'success' | 'declined' | 'error') => {
      await page.route('**/api/payments/process', async (route) => {
        const responses = {
          success: { status: 200, body: { success: true, transactionId: 'TXN-123' } },
          declined: { status: 400, body: { success: false, error: 'card_declined' } },
          error: { status: 500, body: { error: 'Internal error' } },
        };
        await route.fulfill({
          status: responses[result].status,
          contentType: 'application/json',
          body: JSON.stringify(responses[result].body),
        });
      });
    };
    await use(mock);
  },
});

test('handles declined payment', async ({ page, mockPayment }) => {
  await mockPayment('declined');
  await page.goto('/checkout');
  await expect(page.getByRole('alert')).toBeVisible();
});
⚠️ Watch Out!

Common Mistakes

  • ❌ Registering route after goto: Page already fetched — mock never runs.
    ✅ Always page.route() before navigation or the triggering action.
  • ❌ Mocking everything in every test: You never hit real integration paths.
    ✅ Mock edge cases; use real API or HAR for happy-path smoke tests.
  • ❌ Stale HAR files: API changed but playback still serves old JSON.
    ✅ Re-record periodically or use notFound: 'fallback' when appropriate.
  • ❌ Forgetting to unroute: Mock leaks into the next test in the same page.
    ✅ page.unroute() or isolate with fresh context per test.
📝 Summary

Key Takeaways

  • page.route() intercepts any network request
  • Three patterns — Fulfill (mock), Continue (modify), Abort (fail)
  • Edge cases — payment declines, inventory, shipping, retries
  • HAR — record and replay real traffic
  • Mock fixtures — reusable declined/success/error helpers
  • Conditions — slow API, offline, intermittent 500s
